# Что видят участники сети Aira

> Версия документа: сентябрь 2026. Статусы как в `docs/THREAT_MODEL.md`: **код** / **M<N>** (план) / **нет**.
> В Aira нет центрального сервера, аналитики и телеметрии: проект не собирает никаких данных о пользователях.

## Собеседник (контакт)

| Данные | 0.3.5 | Бета 0.5 (M19/M20) | M24b |
|---|---|---|---|
| Ваш IP | при прямом соединении — да (сети пока нет) | **нет** (relay-only по умолчанию); да — только если вы включили «прямое соединение» для этого контакта | нет |
| Ваш EndpointId и relay | да | да | не видит relay/guard |
| Время онлайн, typing, receipts | да (отключаемы per-contact) | да | да |
| Содержимое | да, это ваш собеседник | да | да |

## Оператор iroh-relay (транспортный relay)

Видит: ваш публичный IP, EndpointId (Ed25519), время подключений, объёмы трафика, EndpointId пиров, с которыми
вы обмениваетесь пакетами через него. Не видит содержимого (E2E). Логи iroh-relay по умолчанию пишут IP клиента
в каждую строку уровня `info` — операторам Aira предписан `RUST_LOG=warn` (docs/RELAY.md, M21). До M20 relay —
публичные серверы n0 (они видят то же самое и заявляют «не для sensitive data»); с M20 — relay проекта и сообщества.

## Оператор aira-relay (mailbox)

Видит: `mailbox_id` (псевдонимный, две коробки на пару), размер и время конвертов, публичные owner/sender-ключи
коробки, EndpointId/IP того, кто кладёт и забирает конверты (до M24b — это вы и ваш контакт; с M24b — последний
хоп маршрута). Не видит содержимого, не может связать коробки одного пользователя между собой (v2, M21).
Push-уведомление — пустой wake-up без mailbox_id по allowlist URL.

## Хоп Aira Onion (M24b)

Guard видит ваш IP и следующий хоп, но не адресата. Middle не видит ни вас, ни адресата. Хоп никогда не открывает
соединений к произвольным хостам и переносит только ячейки фиксированного размера (инварианты AP-1…AP-7).
Ваша хоп-идентичность — отдельный ключ, не связанный с чат-идентичностью.

## Провайдер / DPI

Видит адреса relay/мостов, к которым вы подключаетесь, объёмы и время; до M24c — распознаваемый QUIC/TLS.
Содержимого не видит.

## Локально на устройстве

- База `~/.aira/aira.redb` зашифрована ключом из seed-фразы; ключ — в OS keychain (или под паролем, Settings → Security).
- Seed-фраза (24 слова) — единственный способ восстановления; проект её не хранит.
- `pending_messages` и логи не содержат plaintext после M19 Phase A (сейчас групповой fan-out кладёт plaintext — группы отключены).
- Права на файлы/сокет 0700/0600 — M19b.

## Что проект не собирает

Ничего: нет crash-репортов, нет аналитики, нет push-серверов проекта (UnifiedPush — ваш сервер), нет учёта пользователей.
Каталог relay (M24a) публикует записи relay-операторов, но не пользователей; hidden-ноды в каталог не попадают.
